# 🛡️ Organización Isasa

Landing institucional para un broker de seguros, publicada en producción.

## 🔗 **Demo:** https://organizacionisasa.com.ar

## ✨ Características
- Banner principal y carrusel de compañías aseguradoras
- Secciones: Sobre nosotros, Por qué elegirnos y Nuestros ramos
- Formulario de contacto
- Diseño responsive con Tailwind CSS
- Componentes reutilizables en React

## 🛠️ Tecnologías
React · Vite · Tailwind CSS · JavaScript · Git · Vercel

## 💡 Sobre el proyecto
Desarrollado con conocimiento del negocio asegurador desde adentro: trabajo en el broker y el contenido de la web refleja cómo se comunican los servicios a clientes y productores.
